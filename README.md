# Interactive Contact-Us Form ✉️

A vanilla JavaScript mini-project built during the **ITI (Information Technology Institute)** JavaScript course. A styled contact form passes user data between pages via **URL parameters** and greets the user by name — plus a set of small JS exercises bundled in.

## ✨ What It Does

- **Contact form** (`index.html`) — collects first name, last name, and phone number
- **URL-parameter handoff** — form data is encoded into the query string and read on the next page with `URLSearchParams`
- **Personalized welcome** (`userStart.html`) — greets the user by name, or falls back to "Welcome Guest"
- **Theme toggle** — switch between light and dark mode
- **Bonus exercises** — alert-on-click button and a simple four-operation calculator with input validation
- **Custom typography** — Google Fonts (Karla)
